## Projects & multi-tenancy

- Renamed "studies" to **projects** across the app, API, routes, and components
- Project-scoped access control (ACL) with per-user membership and roles
- Multitenancy design documentation and Architecture Decision Records (ADRs)

## Security & compliance

- HIPAA-compliant bcrypt rounds for password hashing
- Break-glass password support with dedicated documentation
- Per-user notebook API keys with JWT-or-key authentication on datasets and project endpoints
- Optional email one-time-code login (SMTP) alongside password sign-in

## Notebooks

- Single-user notebook workflow with JWT-authenticated server endpoints
- Token-only client SDK, sample data loader, and token generator
- Updated band wear analysis notebook
